Classic ASP fixes: broken vs fixed

Ten problems that keep turning up in old Classic ASP / IIS / SQL Server applications. Each page explains the symptom in plain language and shows the broken and fixed code side by side, with runnable broken.asp and fixed.asp files.

BROKENFIXED

01. SQL injection in string-built queries

Visitor text glued into SQL lets anyone read or wipe your data. Fix: ADODB.Command parameters.

BROKENFIXED

02. "Operation is not allowed when the object is closed" and connection leaks

Recordsets used after their connection is closed, and connections never released. Fix: GetRows, then close everything.

BROKENFIXED

03. Garbled text: JosÃ©, â€™ and ???? instead of real characters

Accents, Hindi and curly quotes break on the way in or out. Fix: UTF-8 end to end, NVARCHAR and N'' strings.

BROKENFIXED

04. Users logged out and carts emptied at random (Session loss)

Session() data vanishes on app pool recycles, web gardens and load balancers. Fix: keep important state in the database.

BROKENFIXED

05. "500 - Internal server error" that hides the real problem

Generic 500 pages and On Error Resume Next hide what actually failed. Fix: see real errors safely, log them with a reference.

BROKENFIXED

06. Cross-site scripting (XSS) from unencoded output

Visitor text written straight into HTML can run scripts in other users' browsers. Fix: encode every output with Server.HTMLEncode.

BROKENFIXED

07. Slow pages from N+1 queries and row-by-row loops

One query per row turns a report into thousands of round trips. Fix: one JOIN/GROUP BY query plus GetRows.

BROKENFIXED

08. Calling modern REST/JSON APIs: TLS 1.2 errors and fragile parsing

Payment, SMS or shipping API calls fail with secure-channel errors or break on small changes. Fix: ServerXMLHTTP 6.0, TLS 1.2, timeouts, status checks.

BROKENFIXED

09. Date bugs: 03/04 read as 4 March, and "out-of-range" datetime errors

Dates change meaning with server locale and break SQL. Fix: yyyy-mm-dd input, DateSerial parsing, typed date parameters.

BROKENFIXED

10. File uploads that fail, corrupt files or open a security hole

ASP 0104 / ASP 0206 errors, broken files and unsafe saving. Fix: correct limits, one BinaryRead, safe names and folders.
